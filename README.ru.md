# thermoforming-dfm

[English](README.md)

Навык для агента: **проверка детали и формы под вакуумную формовку** — уклоны, радиусы,
предельная глубина, толщина стенки, вентиляция, раскладка на листе. Всё меряется по
сетке модели и сравнивается с правилами, у каждого из которых указан источник.

Открытые DFM-навыки закрывают листовой металл, фрезеровку, литьё под давлением и печать.
Термоформования нет ни в одном, хотя именно так делают большинство крупных тонкостенных
корпусов малыми партиями.

## Что считает

```bash
python3 skills/thermoforming-dfm/scripts/vf_tool.py measure part.stl --pull z --t 3 --blow-share 0.5
```

- **Толщина стенки по закону Иллига** `s = t · F₁/F₂`: кормит вытяжку **свободный лист**,
  а не след детали, поэтому ответ зависит от раскладки на заготовке. Распространённая
  замена «площадь детали / её след» ошибается вдвое.
- **Площадь, которую накрывает лист, меряется, а не предполагается**: грань накрыта, если
  луч вдоль оси съёма из неё уходит. Ответ одинаков для сплошной модели и для оболочки.
- **Профиль толщины по высоте** с указанием самого тонкого места: материал раскладывается
  по геодезическому пути от точки первого касания — приём из кинематического драпирования
  композитов.
- **Нулевой уклон отделён от артефактов сетки**: прямая стенка читается нулевой на всём
  протяжении, а скругление, лишь проходящее через вертикаль, — только по линии, и его
  фасетки выносятся отдельной строкой; они зависят от плотности сетки и дефектом не
  являются.
- **Уклон со знаком**: стенка, наклонённая не туда, по модулю выглядит приличной, а деталь
  с пуансона не снимется. Отдельно — стенка, до которой лист вообще не дотянется.
- **Поднутрения** строгим критерием: линия вдоль оси съёма пересекает тело больше двух раз
  — материал нависает над материалом, и это не лечится ни уклоном, ни радиусом.
- **Раздув купола числом**: предварительная вытяжка `1 + (h/R)²` и её доля в общей.
- **Требуемый радиус по местной вытяжке**, а не один на всю деталь.
- **Две проверки перед числами**: подозрение на неверные единицы, если деталь меньше
  20 мм или больше 2,5 м, и внятное «не влезает в заготовку» вместо пустого блока
  стенки.
- **Предел глубины по способу**: голый пуансон 0,25, с раздувом 0,5, с плунжером 1,0.
- **Раскладка на листе** и предупреждение, когда формы стоят дальше 1 H от рамы: лишний
  лист — первая причина перемычек.
- **Три точки для замера первой отформованной детали** с ожидаемыми числами.

## Пример

Коробка 200 × 200 × 60, АБС 3 мм, заготовка 500 × 500, купол 37,5 мм:

```
глубина к ширине  0,375           предел для этого способа 0,5 — проходит
деталей с листа   1               F₁ 202 500 мм², F₂ 250 500 мм²
накрыто листом    88 000 мм²      измерено, а не принято за половину модели
средняя стенка    2,43 мм         полоса 1,70 … 3,15
купол             37,5 мм         предварительная вытяжка 1,03, 13 % общей
профиль           2,55 мм сверху  →  2,29 мм у основания
тонкое место      2,01 мм         нижний угол
усилие на форму   358 кгс         проекция × 9000 кгс/м²
нулевой уклон     48 000 мм²      у коробки стенки вертикальные — дать уклон
перемычки         предупреждение  форма в 2,7 H от рамы, лишнего листа много
```

Дальше замерить три точки на первой отформованной детали — и оценка перестанет быть
оценкой.

## Установка

Репозиторий — это **навык для агента** (`skills/thermoforming-dfm/`), обёрнутый в
манифест плагина, чтобы ставился одной строкой.

Плагином в Claude Code:

```
/plugin marketplace add evgeniyzakharow-design/thermoforming-dfm
/plugin install thermoforming-dfm
```

Или просто навыком — скопировать `skills/thermoforming-dfm/` в `.claude/skills/` своего
проекта. От обёртки плагина в навыке ничего не зависит.

```bash
pip install -r skills/thermoforming-dfm/requirements.txt
python3 skills/thermoforming-dfm/scripts/vf_tool.py selftest
```

Python 3.11+, `trimesh`, `numpy`, `scipy`, `rtree` (и `lxml` для .3mf). STEP сначала
экспортировать в STL.

удваивает расход контекста, а отвечает она всё равно на языке вопроса.

## Честно про пределы

Профиль толщины — **геометрический**. Материал перестаёт течь там, где коснулся, а
насколько — зависит от трения и теплового примерзания, которые заменены одной
калибровочной ручкой: в инструментованных опытах эти два эффекта разделить не удалось.
Высота купола задаётся в миллиметрах, потому что секунды у каждого станка свои. И то и
другое калибруется замером реальной детали — для этого в навыке лежит лист для цеха.
До замеров доверяйте форме профиля и месту утонения, а не второму знаку после запятой.
